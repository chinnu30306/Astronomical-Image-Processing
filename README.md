3rd year physics lab - Astronomical Image Processing

- split .fits image into tiles of varying background
- detected galaxies by using local detection threshold for each tile
- measured source magnitudes using circular aperture photometry
- tested completeness by injecting artificial sources across a range of magnitudes and measured recovery rate
- fitted the logarithmic cumulative and differential number counts and compared them with the Euclidean prediction of 0.6
- presented the findings in a presentation
